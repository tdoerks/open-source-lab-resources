# COMPASS Pipeline v1.0.1 Deployment Guide

## What's New in v1.0.1

**Bug Fix Release** - AMRFinder organism mapping for unsupported organisms

### Problem Fixed
- AMRFinder was producing empty output files for organisms not in its supported list (e.g., Pseudomonas aeruginosa)
- Silent failures due to `|| true` made debugging difficult
- All 2,787 Pseudomonas samples in the Phage Hunter study had 0-byte AMRFinder files

### Solution
- Added organism name mapping to AMRFinder-supported codes
- Unsupported organisms (like Pseudomonas) now run in generic mode (no `-O` flag)
- Removed silent failure handling - errors are now logged
- Added diagnostic messages for troubleshooting

### Impact
- **Vibrio cholerae**: ✅ Will now use organism-specific mode (`-O Vibrio_cholerae`)
- **Pseudomonas aeruginosa**: ✅ Will now run in generic mode and produce results
- **All supported organisms**: ✅ Properly mapped (E. coli, Salmonella, Staph aureus, etc.)

## What Changed in the Code

### File Modified: `modules/amrfinder.nf`

**Key Changes:**

1. **Organism mapping** (lines 48-71):
   ```groovy
   def organism_map = [
       'Escherichia coli': 'Escherichia',
       'Vibrio cholerae': 'Vibrio_cholerae',
       'Pseudomonas aeruginosa': null,  // Not supported - will use generic mode
       // ... etc
   ]
   ```

2. **Generic mode for unsupported organisms** (line 75):
   ```groovy
   def organism_flag = amrfinder_organism ? "-O ${amrfinder_organism}" : ""
   ```

3. **Diagnostic logging** (line 79):
   ```bash
   echo "Using organism-specific mode: Vibrio_cholerae" >&2
   # OR
   echo "Using generic mode (organism not in AMRFinder database)" >&2
   ```

4. **Proper error handling** (lines 107-115):
   - Removed `|| true` that was hiding failures
   - Added explicit error logging
   - Still creates empty files for pipeline continuity, but logs the failure

## Supported Organisms in v1.0.1

AMRFinder will use organism-specific mode for:

- ✅ Acinetobacter baumannii
- ✅ Campylobacter (coli, jejuni)
- ✅ Clostridioides difficile
- ✅ Enterococcus (faecalis, faecium)
- ✅ Escherichia (E. coli)
- ✅ Klebsiella (pneumoniae, oxytoca)
- ✅ Salmonella (enterica, etc.)
- ✅ Staphylococcus (aureus, pseudintermedius)
- ✅ Streptococcus (agalactiae, pneumoniae, pyogenes)
- ✅ **Vibrio cholerae** 🎉

AMRFinder will use generic mode (still works!) for:

- Pseudomonas aeruginosa
- Listeria monocytogenes
- Shigella species
- All other organisms
